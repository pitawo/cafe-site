# Cafe Site — 注文から決済までの一連の流れ

カフェの注文サイト（架空のデモ店舗）。**商品を選ぶ → カートに入れる → 決済画面 → 注文完了**までを、実際に触って確かめられる。

![React](https://img.shields.io/badge/React-19-61dafb) ![Vite](https://img.shields.io/badge/Vite-7-646cff) ![Vitest](https://img.shields.io/badge/tests-15%20passing-brightgreen)

## 触れるところ

| 画面 | できること |
|---|---|
| ホーム | お知らせ・営業時間（すべて架空のデモ用） |
| メニュー | ドリンク6品（S/M/L でサイズ選択・サイズで価格が変わる）＋ スイーツ・フード6品 |
| カート | 数量の増減、削除、小計の確認。画面右下に固定のカートボタン（0点のときは非表示） |
| 決済 | 注文明細・消費税・配送料を計算し、支払いへ進む |
| 完了 | 受付番号・注文者・受け取り方法・支払い金額を表示 |
| サインイン | **入力は任意**。空のままゲストとして続けられる。サインイン後は自動でメニューへは飛ばず、元いた画面に戻る |

## 決済について

**このデモでは決済を行わない。** ただし決済画面そのものは省略していない。カード番号・名義・有効期限・セキュリティコードの入力欄を持ち、金額の内訳も計算して出す。

**カード情報はデモ用の値が入力済みで、読み取り専用にしてある。** 訪問者が実在のカード番号を打ち込む余地をなくすため。入力された内容がブラウザの外に送られることはない。

支払いボタンを押すと 1.4 秒の待ち時間を挟んで完了画面へ進む。決済にかかる時間を再現しているだけで、外部への通信はしていない。完了画面には `DEMO-YYYYMMDD-XXXX` 形式の受付番号を表示する（ブラウザ内で発行するだけで、外部との通信はない）。

## 金額の計算

```
単価    = ドリンクは S 基準額（M は +¥50 / L は +¥100）、フードは固定額
小計    = 各商品の単価 × 数量の合計
消費税  = 小計 × 10%（円未満切り捨て）
配送料  = 店頭受け取り ¥0 / 配達 ¥300
合計    = 小計 + 消費税 + 配送料
```

受け取り方法を切り替えると合計が変わる。

## 状態の持ち方

カートとサインイン状態は `localStorage` に置いてある。**画面を読み込み直しても中身が消えない。** 保存できない環境（プライベートモードなど）では、その回のあいだだけ保持する。

| キー | 内容 |
|---|---|
| `cafe-site/cart` | カートの中身（ドリンクはサイズ違いを別明細として扱う） |
| `cafe-site/user` | サインインした利用者（パスワードは保持しない） |

## 動作確認

購入の流れを Testing Library で確かめている（15項目）。

- ホーム：架空のお知らせ・営業時間が出て、デモである旨が明記されている
- カート：追加で件数が増える／`localStorage` に残る／空では決済に進めない／サイズを変えると金額が変わる
- 決済：小計・消費税・合計を計算する／配達を選ぶと配送料が加わる／**カード欄は打ち込んでも変わらない**
- 完了：カートが空になり、金額と受付番号が表示される
- サインイン：空のままでも進める／元いた画面に戻る（自動でメニューには飛ばない）／**パスワードの入力欄を持たない**
- カートボタン：0点のときは出ない／追加すると画面右下に固定表示され、件数バッジが増える

テストが本当に機能しているかは、実装をわざと壊して確かめた。`readOnly` を外すとカードのテストだけが落ち、税率を 10% から 8% に変えると金額を見ている3件が落ちる。

## 画像

すべてローカルで用意したものを同梱している（`src/assets/`）。フリー素材サイトからのダウンロードはしていない。ページから外部への通信も無い。

| 用途 | ファイル | 備考 |
|---|---|---|
| 店の外観 | `storefront.webp` | トップの背景。文字を読ませるため暗い膜を重ねている |
| ロゴ | `logo.png` | ヘッダー用。円形のエンブレム型。塊として見えるので小さくしても形が残る |
| ドリンク6品 | `menu/*.webp` | 俯瞰・明るい木目・斜めから入る自然光で揃えた実写 |
| スイーツ・フード6品 | `menu/*.svg` | 実写を用意できないため、ブランドカラーに合わせた線画イラストで代替 |

## 作っていないもの

- 認証サーバー。サインインはブラウザの中だけで完結する
- 在庫や注文履歴。注文は保存されず、完了画面を出して終わる（受付番号もその場で発行するだけで記録は残らない）

## このサイトについて

実在の店舗・ブランドではない、ポートフォリオ用のデモです。ホーム画面のお知らせ・営業時間もすべて架空の内容です。
