# Cafe Site — 注文から決済までの一連の流れ

カフェの注文サイト。**商品を選ぶ → カートに入れる → 決済画面 → 注文完了**までを、実際に触って確かめられる。

![React](https://img.shields.io/badge/React-19-61dafb) ![Vite](https://img.shields.io/badge/Vite-7-646cff) ![Vitest](https://img.shields.io/badge/tests-10%20passing-brightgreen)

## 触れるところ

| 画面 | できること |
|---|---|
| メニュー | 6品から選んでカートに入れる |
| カート | 数量の増減、削除、小計の確認 |
| 決済 | 注文明細・消費税・配送料を計算し、支払いへ進む |
| 完了 | 注文者・受け取り方法・支払い金額を表示 |
| サインイン | **入力は任意**。空のままゲストとして続けられる |

## 決済について

**このデモでは決済を行わない。** ただし決済画面そのものは省略していない。カード番号・名義・有効期限・セキュリティコードの入力欄を持ち、金額の内訳も計算して出す。

**カード情報はデモ用の値が入力済みで、読み取り専用にしてある。** 訪問者が実在のカード番号を打ち込む余地をなくすため。入力された内容がブラウザの外に送られることはない。

支払いボタンを押すと 1.4 秒の待ち時間を挟んで完了画面へ進む。決済にかかる時間を再現しているだけで、外部への通信はしていない。

## 金額の計算

```
小計    = 各商品の単価 × 数量の合計
消費税  = 小計 × 10%
配送料  = 店頭受け取り $0.00 / 配達 $3.00
合計    = 小計 + 消費税 + 配送料
```

受け取り方法を切り替えると合計が変わる。

## 状態の持ち方

カートとサインイン状態は `localStorage` に置いてある。**画面を読み込み直しても中身が消えない。** 保存できない環境（プライベートモードなど）では、その回のあいだだけ保持する。

| キー | 内容 |
|---|---|
| `cafe-site/cart` | カートの中身 |
| `cafe-site/user` | サインインした利用者（パスワードは保持しない） |

## 動作確認

購入の流れを Testing Library で確かめている（10項目）。

- カート：追加で件数が増える／`localStorage` に残る／空では決済に進めない
- 決済：小計・消費税・合計を計算する／配達を選ぶと配送料が加わる／**カード欄は打ち込んでも変わらない**
- 完了：カートが空になり、金額が表示される
- サインイン：空のままでも進める／**パスワードの入力欄を持たない**

テストが本当に機能しているかは、実装をわざと壊して確かめた。`readOnly` を外すとカードのテストだけが落ち、税率を 10% から 8% に変えると金額を見ている3件が落ちる。

## 作っていないもの

- 認証サーバー。サインインはブラウザの中だけで完結する
- 在庫や注文履歴。注文は保存されず、完了画面を出して終わる
- 商品画像。プレースホルダを使っている
